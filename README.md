# Visite Management Application

---

1. Make sure thartt your IDE or code editor will convert your indentations to tabs.
2. `Make` is the build tool system that we are using in this project. Make sure that you have it in your OS distro.


## Build and run the containers

- `make build`

## Run the containers only

- `make run`

## Stop the containers

- `make stop`

## Run the migrations only

- `Make runMigrations`

## Clean up Docker containers

- `Make clean`
